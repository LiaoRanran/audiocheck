# 测量原理与误差边界

本文说明每个数字**怎么来的**、**依据哪个标准**、**什么情况下不可信**。
一个不给误差边界的指标，比没有这个指标更糟——它会让人做出过度自信的判断。

---

## 1. 真实截止点（本项目最核心的判据）

### 1.1 为什么不能用"看频谱图"代替

人眼看频谱图只能判断"大约在哪"，而判定「44.1k 的 19.6k」与「48k 的 21.4k」需要
±0.2kHz 的稳定性。所以必须有确定性的算法。

### 1.2 算法（第五代，前四代都踩过坑）

```
1. 在**未平滑**的原始 Welch 谱上自高向低扫描
2. 在每个候选点 fc，比较两个窗口的中位数：
      下方 [fc/1.6, fc]  与  上方 [fc, min(fc*1.6, nyq)]
   若 下方 − 上方 ≥ min_drop_db（默认 15dB），认定此处存在陡降（**粗候选**）
3. 取阈值 =（通带中位数 + 阻带中位数）/ 2
   ⚠ 通带中位数取自**不跨骑候选**的窗 [fc/2.56, fc/1.6]（见 §1.6，v4.1 修）
4. 在原始谱上自高向低找第一个连续 3 点越过该阈值的位置，即为截止点
```

### 1.3 历代错法的成因（保留在此，防止退化）

| 版本 | 做法 | 错在哪 | 症状 |
| --- | --- | --- | --- |
| v1 | 按 1/12 倍频程步进下降，累计 N 步取当前频率 | 累计到 N 步时已越过边缘 N−1 步 | **恒定偏低**：44.1k 满带宽文件恒报 `22050/2^(2/12)=19.64k`，把满带宽 CD 误判成"轻微带限" |
| v2 | dB 域平滑 + 深阈值找边缘 | dB 域是算术平均，一半通带一半阻带会得到 `(0 + −90)/2 = −45dB`，边缘被抹成 12% 宽的过渡带 | **系统性偏高约 8%** |
| v3 | 功率域平滑 + "通带中位数 −3dB"的半功率点 | 用**全频段**中位数做参考；真实音乐的谱本身随频率向下倾斜，找到的是"谱穿过中位数的位置" | 一份实际延伸到 25kHz 的 96k 文件被判成 **6.8kHz** |
| v4 | 局部陡降 + 中点阈值（本文档 §1.2 步骤 1–2、4） | — | 合成基准误差 **−0.0%** |
| **v4.1** | v4 + **通带参考窗不跨骑候选**（§1.6） | v4 的通带参考窗 `[fc/1.6, fc]` 会跨骑候选；粗候选常落在真边缘上方 1.2–1.33× | **系统偏高**：96k 低截止 +25%、44.1k +10%（见 §1.6） |

### 1.4 两条必须遵守的实现细节

- **平滑必须在功率域**。dB 域的算术平均没有物理意义；功率域平均下，一半通带一半阻带恰好得到 −3dB（半功率点）。
- **扫描必须用原始谱**。功率域平滑窗口为 ±1/6 倍频程（≈±12%），当截止点距奈奎斯特很近时（如 44.1k 容器、内容到 19.5k），平滑后上方只掉 8.6dB，判定器完全看不见。

### 1.5 误差与不可测区间

| 情形 | 表现 |
| --- | --- |
| 陡降明显（有损/升频） | 相对误差 **≤1.3%**（v4.1 起；v4 时最低到 96k 的 +25%，见 §1.6） |
| 边缘距奈奎斯特 <10% | 分辨率下降，可能报成"直达奈奎斯特"；已用"顶部 5% 频段落差"兜底，但极端情况仍会漏判 |
| 自然滚降（如 2 阶巴特沃斯） | 正确判为"无截止"（阻带不够深，<20dB） |
| 数字静音 | 直接返回"无内容"，不猜 |

### 1.6 v4.1 精度修正：通带参考窗**不能跨骑候选**（2026-10-17）

**发现方式**：E1 属性测试只敢覆盖 ≥12 kHz、容差松到 15%（当时登记"9–12 kHz 精度判据未立"）。
本轮把误差**曲面**量出来（入库探针 `packaging/cutoff_calib.py`，密集网格 × 三采样率），
看到 96k 低截止处系统性偏高：**+25%（6 kHz）、+15.6%（8 kHz）、+14.7%（9 kHz）**。

**机制**（打中间量证实，不是猜）：粗候选来自 1/12 倍频程步进，
常落在真边缘上方 **1.2–1.33×**。此时 v4 用来算阈值的通带参考窗 `[fc/1.6, fc]`
**跨骑**了边缘 ⇒ 窗内通带占比 <50% ⇒ **中位数落到阻带底** ⇒ `thr=(通带+阻带)/2`
塌陷到数值噪声底 ⇒ 第 4 步命中的是"噪声底越过该电平"的位置，**系统性偏高**。

**修法**：通带参考窗改为**带间隙、不跨骑**的 `[fc/2.56, fc/1.6]`（因候选 <1.6× 真边缘，
此窗必在通带内）；**粗搜索与守卫窗一字未改** ⇒ **"是否判为带限"的集合不变**
（`cutoff=None` vs 有值 的决定不动），只有带限文件的截止点**读数**变准。

⚠ **读数变化会传导到判定等级**：判定把 `cutoff_hz` 与 `hi_ok`/`ltd`/`lossy` 等门限比较，
读数下移会让**跨门限的文件改档**（不是"只动值不动判"——那是草率结论，已更正）。
同一份真实曲库只换 cutoff 实现对照跑（448 文件）实测：**等级翻转 55/448**、
`ok 82→78`/`warn 226→227`/`bad 140→143`；截止点中位变化 0.12 kHz、最大 11.35 kHz。
方向是**修正**：旧值把 96k 内容截止点报得虚高 ⇒ 误判"真 Hi-Res"。
（复算器：`packaging/cutoff_impact.py`，`--make-old` 可把旧实现覆盖进当前模块以隔离变量。）

**实测（250 Hz 步长扫 [6000,21000] × {44.1k,48k,96k}，`packaging/cutoff_calib.py`）**：

| 指标 | v4 | v4.1 |
| --- | --- | --- |
| 最大相对偏差 | **25.0%**（96k @ 6 kHz，44.1k 10.0%） | **1.27%**（96k @ 6 kHz） |
| 最大跨采样率散布 | 10.2% | **0.69%** |
| 满带宽 / 自然滚降 / E1 回归点（合成） | 不变 | **不变**（逐点核对） |
| 真实曲库判定等级 | — | **55/448 改档**（更准）；全量 450 文件 = ok 78 ｜ warn 229 ｜ bad 143 |

属性测试据此从「≥12 kHz、15%」收紧到「**[6,21] kHz、3%**」（`tests/test_props.py`）。

## 2. 响度：ITU-R BS.1770-4

### 2.1 K 加权

两级 biquad，系数按**实际采样率实时重算**（不是照抄 48kHz 表）：

**第一级：高架滤波**（补偿人头对高频的增益）
```
f0 = 1681.974450955533 Hz,  G = +3.999843853973347 dB,  Q = 0.7071752369554196
K  = tan(π·f0/fs),  Vh = 10^(G/20),  Vb = Vh^0.4996667741545416
b = [(Vh + Vb·K/Q + K²)/a0,  2(K² − Vh)/a0,  (Vh − Vb·K/Q + K²)/a0]
a = [1,  2(K² − 1)/a0,  (1 − K/Q + K²)/a0],   a0 = 1 + K/Q + K²
```
**第二级：高通**（去除次声与直流）
```
f0 = 38.13547087602444 Hz,  Q = 0.5003270373238773
b = [1, −2, 1],  a = [1, 2(K²−1)/a0, (1 − K/Q + K²)/a0]
```

### 2.2 门限积分

```
块长 400ms，步进 100ms（= 4 个 100ms 步，用卷积做滑窗，矢量化）
逐块均方 z_j = Σ_channels mean(y²)
块响度 l_j = −0.691 + 10·log₁₀(z_j)

绝对门限：保留 l_j > −70 LUFS
相对门限：阈值 = (绝对门限内均值对应的响度) − 10 LU，再筛一次
积分响度 = −0.691 + 10·log₁₀( Σz_gated / N_gated )
```

**为什么必须门限**：不门限的话，一段长静音会把整轨响度拖低好几 LU，
不同曲目的读数就不可比了。这是 BS.1770 与"简单 RMS"的本质区别。

### 2.3 验证方式

测试用"同一正弦、幅度减半"，断言响度下降 **6.02 LU**。
这比断言绝对值稳——它验证的是**标度不变性**，不依赖具体实现细节。

## 3. 响度范围 LRA：EBU R128 Tech 3342

在 K 加权信号上取**短时块 3s / 步进 1s**，同样做 −70 LUFS 绝对门限
与 −20 LU 相对门限，然后：

```
LRA = P95(短时响度) − P10(短时响度)
```

取 P95/P10 而非 max/min，是为了排除个别极值段的干扰。

> **DR 与 LRA 的区别**：DR（动态范围）是行业惯用的近似指标，本项目给出的
> `dr_db = 采样峰值 − 最响 20% 块的均方根`，**明确是近似 TT-DR，不宣称等同
> 官方 DR Meter 输出**（官方算法未完整公开）。真正标准化、可复现的动态量是
> **LRA**。判断"能不能用来评耳机动态"时应看 LRA。

## 4. 真峰值：ITU-R BS.1770-4 Annex 2

采样点不超 0 dBFS，不代表**重建后的模拟波形**不超。
在 DAC 的插值重建中，相邻采样点之间可能过冲。

```
对每个声道做 4 倍过采样（多相 FIR 重采样），取过采样序列的峰值
true_peak_dbfs = 20·log₁₀(max|x_oversampled|)
```

**实现细节**：分段重采样时丢弃每段首尾各 10%，避免滤波器边界瞬态造成的虚假峰值。

**为什么重要**：真峰值 > 0 dBTP 意味着在真实 DAC 上会削顶——
这是"母带做过了"的确凿证据，且**不该算到耳机头上**。

## 6. 位深升位检测（**可作证据**）

### 6.1 原理

把 16bit 内容装进 24bit 容器，有两种写法：
- **补零**（常见）：`stored24 = v16 << 8` → 存储值低 8 位恒为零
- 直接写入：`stored24 = v16` → 这只是"电平低"，**不是升位**

### 6.2 实现要点（踩过的坑）

libsndfile 把整数 PCM 读成 `int32` 时会**左移对齐**：24bit 内容读到的是 `stored24 << 8`。
所以"低位全零"里有一部分是**格式固有**的，必须先扣除：

```
inherent = 32 − 标称位深        # 24bit → 8
low      = 所有样本按位或后的最低置位
extra    = low − inherent       # 这才是真正的填充位数
若 extra > 0 → 实为 (标称位深 − extra) bit
```

**为什么不能用电平判断**：安静的 24bit 素材本来就用不满位数，
按"有效量化级数"反推会把它误判成升位。**电平和位深是两回事**。

## 7. 频谱估计：Welch 法与它的边界

```
分段：取 25% / 50% / 75% 三处各 20 秒，做 Welch 平均后相加
参数：nperseg = 16384，50% 重叠，Hann 窗
```

- **频率分辨率** = `fs / nperseg`：44.1kHz 下约 **2.7 Hz**；
- **平滑段数** ≈ 20 段 → 单点估计的标准差约 ±1.2dB；
- 这解释了为什么截止点检测要在**原始谱**上找陡降，而不是在单点上比大小。

**可测下限**：频率下限受窗口长度限制，本项目取 20Hz 作为有效下界
（`f[0]=0` 是直流分量，**不能**作为循环下界——这是 v1 死循环事故的根因）。

## 9. 汇总：哪些数字能当证据

| 指标 | 可作证据？ | 理由 |
| --- | --- | --- |
| 真实截止点 | ✅（陡降明显时） | 确定性算法，误差 <1% |
| 真峰值 | ✅ | 标准定义，4 倍过采样 |
| 集成响度 / LRA | ✅ | 标准定义，门限逻辑完整 |
| 位深升位 | ✅ | 位级判据，与电平无关 |
| 削波样本比例 | ✅ | 直接计数 |
| 编码器类型 | ⚠️ 线索 | 典型值，非唯一解 |
| DR | ⚠️ 近似 | 官方算法未公开 |
| 频段能量占比 | ⚠️ 参考 | 依赖 Welch 参数与取样位置 |
| 谱低端百分位 | ⚠️ 参考 | **不是噪声底**——它是频谱第 5 百分位，不代表静音段的本底 |

### 9.1 本表是**权威**：UI 不许展示表里没有的数字

C0-5 立的规矩。两条：

1. **界面上出现的每一个数，都必须能在这张表里找到它（以及它的可信度）。**
   找不到就不许显示——"看起来是个测量值"和"真的是个测量值"必须一致。
   反面例子（已修）：`noise_floor_db` 实际是**频谱第 5 百分位**，却在指标卡与
   图表参考线上都叫"**噪声底**"。叫噪声底会让人以为它来自静音段测量，
   而"静音段"在本项目里**没有判据**（要立判据就得先定"多静算静音"这个新阈值，
   属 C1 的范围）。现在按实际含义命名：**谱低端百分位**。
   （数据键仍叫 `noise_floor_db`，为 JSON 兼容；界面文案不许再写"噪声底"。）

2. **表里的可信度等级要跟着数字走。**标 ⚠️ 的指标在报告/导出里不许
   以确定语气出现（"DR 为 8.2" 要写成 "DR ≈ 8.2（近似）"）。

### 9.2 C4 立的三条输出规矩（用户 2026-10-13："极致真实丰富"）

1. **三层分开，不许压平**：现象层（`phenomena`）／成因层（`causes`）／用途层
   （`usability`）各自成结构。成因候选**并列输出**并标"无法区分"，不许压成
   一个结论；用途矩阵不许压成分数；判定行不许用"｜"糊成一行。
2. **证据不足不硬判**（C4.6）：砖墙陡度不足（conf < `conf_low`）时，带限类
   判定只能 `warn` 不能 `bad`——"有损溯源"是对**成因**的硬断言，需要陡砖墙
   作证据。等级（level）与成因（causes）分开：level 答"有不有问题"，
   causes 答"像什么原因"。
3. **"未知"是正式取值**：缺数据 ⇒ "不可判"（用途矩阵）／"无法统计"（位深），
   不许默认成"没问题"。每次运行印一次 `boundaries`（效力边界）。

## 10. 假 Hi-Res 盲检测（C3）：一个**负结论**的方法节

方法链来自 NYCU 2017 学位论文（席冠文、羅濟群；**学位论文、未独立复现**，
引用它不等于采信它的 98%）：
**取差分 → 取绝对值 → 取对数 → FFT → 对数等距 6 段取均值作特征 → 分类**。
本项目用自实现逻辑回归（不引运行时依赖；SVM→LR 是为系数可读可复算）。

**自建验证集的实测结论（可复算：`python packaging/fakehires_eval.py`）**：

| 集 | 内容 | 结果 |
|---|---|---|
| 训练 | 粉噪/白噪 ×（原生 / 升频 / 有损后升频） | 准确率 0.875 |
| 测试 | 没见过的"类音乐"内容 | **误报率 0.722** |

**归因（拆开看的）**：L2 归一后的 6 段特征是**整体谱形描述**，被内容滚降
主导——噪声源上"假"样本顶部带塌掉、差异大；谱形自然滚降的内容上差异小。
真正把两类分开的是"22 kHz 以上有没有真实能量"，而**那一项本项目已经有
`cutoff_hz` 在测、且更可靠**。

⇒ **判定：该特征不构成截止点之外的增量，且跨内容类型不泛化。**
输出一个测试集误报率 72% 的分类器比没有它更糟（用户会去信）⇒ 分析器
**默认关闭**（`enabled = False`，判定写进源码 docstring），代码与验证脚本
保留。重开：`--only fakehires`。升格为判据的前提：**真实曲库**上误报可接受
（未做）。调参过程中的三次失败（训练集 recall=0 ⇒ 类不平衡；测试集误报
0.806 ⇒ 语料"类音乐"名不副实）记在 `tests/test_c3_fakehires.py` 与 CHANGELOG。

## 11. 判定层理论：三层输出的认识论（C4，2026-10-16 落纸）

用户原话："判决颗粒度一定要根据现实音源复杂情况极致真实丰富。"
本节回答**为什么必须是三层**，以及每层的推理规矩从哪来。

### 11.1 三层的认识论定位

| 层 | 输出 | 推理类型 | 规矩 |
|---|---|---|---|
| 现象层 | 测量值 + 等级 | **测量**（确定性） | 每个数有出处或标"工程估计"；区分力可查 |
| 成因层 | 候选集 + 证据/反证/强度 | **溯因推理**（abduction） | 并列候选、不许硬判一个；无出处标"疑似" |
| 用途层 | 每格 可用/受限/不可用/不可判 | **测量效度映射** | 每格带依据；判不了的写"不可判" |

三层的错误是不同的东西，混在一层就全都失真：把"像什么原因"（溯因，天然
不确定）压进"有不有问题"（测量，要求确定），等级就不再表达任何明确的
东西——这是 C4 之前的病；把"能拿它评什么"（效度）塞进成因，用户会以为
结论在说文件而不说用途。

### 11.2 溯因推理的规矩（皮尔斯框架的项目化）

1. **候选 ≠ 结论**。现象支持多个相容假设时，输出**全部候选** + 各自证据；
   "无法区分"是**正式状态**（`ambiguous` 标记），不是失败。
   实例：黑胶 vs 磁带——区分证据是 wow/flutter（抖动）与爆音，**本项目
   测不了**，所以两者永远并列出现，直到有判据。
2. **反证与证据对称**。候选带 `counter[]`：硬砖墙是黑胶的反证（更像转档）。
   只有支持证据没有反证检查的候选，是在做确认偏误。
3. **强度（strength）的统计定义**：砖墙类候选的 strength 就是带宽轴的
   `conf`——砖墙陡度在证据区间 [8, 24] dB/oct 上的**归一化位置**。
   ⚠ 它**不是概率**（p(有损｜谱) 需要先验，我们没有），不许在文案里写成
   "概率"或"置信度 %"。非 conf 派生的粗档（0.5/0.8/0.9）是**证据类型的
   工程分级**（统计吻合/容器级失配/位级），同样不是概率。
4. **出处分级 ↔ 判据强度**：位级判据（位深填充）可作硬证据；有学术出处
   （升频，NYCU 2017）可作线索级；工程估计一律"疑似"。**无出处不许当
   证据用**——C2 出处账与 §9 表是这个映射的账本。

### 11.3 文献锚点（2026-10-16 主线 A 清查，详见 docs/research.md §4）

* **双压缩检测**（有损转码候选的未来证据方法）：Liu, Sung & Qiao,
  *Cognitive Computation* 2(4):291–296, 2010；Yang, Qu & Huang, Proc. SPIE
  7541, 75410K, 2010。MDCT 域统计量——本项目当前只用截止点+砖墙（工程
  估计），这条线给出"转码链"判据的升级路径（需 MDCT 访问，libsndfile 不给，
  挂账）。
* **假立体声**（候选已可锚定）：Liu, Yan, Wang, Yan & Chen, *Identification
  of Fake Stereo Audio Using SVM and CNN*, **Information** 12(7):263, 2021
  （MDPI，同行评审）；正向模型见 Kraft & Zölzer, DAGA 2015（M/S 上混）。
* **母带限幅**：仍**文献债未清**——PLR/DR 的行业来源（TT 计量）不是同行
  评审，门限保持工程估计。

### 11.4 用途矩阵的理论：测量效度

"能拿它评什么" = **测量效度**问题：一个指标能不能回答某个问题，取决于
问题的信息是否存在于测量里。三条推导规矩：

1. **信息在源头就没了 ⇒ 不可用**（内容止于 16kHz 评不了高频延伸）；
2. **问题被别的失真掩盖 ⇒ 受限**（削波掩盖细节、响度战掩盖动态）；
3. **测量原理上不覆盖 ⇒ 不可判**（结像需要双耳数据——**不是"没问题"，
   是"问错了工具"**；瞬态受 93ms 分析窗限制）。

这就是"未知是正式取值"的效度版本：`不可判` 与 `可用` 一样是**有信息的
结论**，压平成"没问题"才是失真。

## 12. 编辑器数学基础（2026-10-18；每条都标注"**它是判据，不只是知识**"）

> 出处口径：标「已核」的给了出处；经典结论但本轮**没核到正式出处**的标「未核」。
> 相关取证见 `docs/editor_research.md`。

### 12.1 STFT 与完美重建（COLA / NOLA）

分析 `X_m[k] = Σ_n x[n]·w_a[n−mH]·e^{−j2πkn/N}`；合成用加权重叠相加（WOLA）
`x̂[n] = Σ_m (合成窗/IDFT) · w_s[n−mH]`。在 `X' = X`（不动谱）时，逐点还原为

```
x̂[n] = x[n] · Σ_m w_a[n−mH]·w_s[n−mH]  /（归一化常数）
```

⇒ **完美重建条件（常数重叠相加，COLA）**：`Σ_m w_a[n−mH]·w_s[n−mH]` 必须
**在整个 n 上为同一非零常数**（NOLA 是它的更弱形式）。
⇒ **判据**：改 hop `H` 或窗 `w_a/w_s`，**必须重新验这条恒等式**——不许用"听起来没变"当通过。
这条还把两件事绑死：**视图用的 STFT 参数与编辑用的必须同一套**，否则编辑完再看图会见到残差，
而残差会被误当成"修复没做干净"。

### 12.2 削波模型与它的**可辨识性**（不靠猜）

硬削波：`y[n] = clip(s[n]; c) = min(max(s[n], −c), c)`。逐样本看：

* `|y[n]| < c` ⇒ **`s[n] = y[n]` 精确已知**（无损段）；
* `|y[n]| = c` ⇒ 只知道 `s` **越过了 ±c**，**符号已知、幅度未知**（饱和段）。

⇒ **这不是"猜"**：饱和段的位置与个数、以及 `c`，都是**可测**的输入。
⇒ **判据**：任何去削波实现必须报 ① 饱和样本数与占比 ② 估计的 `c`；
真值改进用 **SDR**（合成语料，有真值）。评测口径参考 **Záviška/Rajmic et al.,
IEEE JSTSP 2020「已核」**（该文正用 SDR + 感知指标做大规模评测）。
⚠ **PHAIN（IEEE 2024「已核」）** 指出：纯稀疏推广会**把幅度压小**、且忽略正弦的时间连续性
⇒ 故必须**同时**量"修复段能量比"（修复后 RMS / 真值 RMS），否则"变安静"会被误判成"修好了"。

### 12.3 Inpainting：analysis vs synthesis 稀疏（修复的**统一骨架**）

**A. Adler, V. Emiya, M. G. Jafari, M. Elad, R. Gribonval, M. D. Plumbley.
*Audio Inpainting*. IEEE TASLP 20(3), 2012「已核」**把削波 / 脉冲噪声 / 丢包统一成
"**位置已知的缺失**"。设 `M` 为已知位置的采样算子、`Φ` 为时频字典（STFT/MDCT），两种算子：

* **synthesis（合成式）**：`c* = argmin ‖c‖₁ s.t. M·Φ·c = y`，重建 `x̂ = Φ·c*`；
* **analysis（分析式）**：`x̂ = argmin ‖Φᵀ·x‖₁ s.t. M·x = y`。

⇒ **判据**：**选哪种算子不是风格问题**——字典不完备时合成式**幅度会缩**，分析式通常
幅度更好但更慢。**选型必须用 12.2 的两条（SDR + 能量比）一起判**，不能凭手感。

### 12.4 量化误差谱与噪声整形（导出链路的基础）

标量量化误差 `e = Q(x) − x`，`|e| ≤ Δ/2`（Δ = 1 LSB）。
加**加性 TPDF 抖动**（三角分布，峰峰 2Δ）后：`E[e] = 0` 且**误差与信号统计独立**
⇒ 量化失真从"与信号相关的谐波"变成"与信号无关的白噪"。
**噪声整形**用误差反馈把误差谱搬走：`e'[n] = e[n] − Σ_{k≥1} h[k]·e'[n−k]`
⇒ 误差功率谱被 `|1/(1 + Σ_k h[k]z^{−k})|²` 塑形，形**按听感阈值曲线**摆放
（**Lipshitz / Vanderkooy / Wannamaker「已核」**）。
⇒ **判据**：16-bit 导出的**误差谱可以算、可以画**（Welch 一下就有）⇒ 抖动方案是**可验证**的。
⚠ **本仓现状：`render()` 还没做抖动/整形**，16-bit 导出只是走 libsndfile 的再量化
——**如实挂账**（见 `CHANGELOG`）。

### 12.5 重采样：带限插值与**可测**的取舍

理想重建 `x(t) = Σ_n x[n]·sinc((t − nT)/T)`；工程上用**加窗 sinc 的 FIR** 截断，
其质量由三个**可算**指标决定：**通带纹波 δ_p / 阻带衰减 δ_s / 过渡带宽度**。
⇒ **判据**：SRC 的质量**不靠耳朵**——扫频或白噪一量就知道。
⚠ 经典出处与具体库（soxr）**本轮未核**，见 `editor_research.md §5`。

### 12.6 相位感知与瞬时频率（修复边界必须连续）

对正弦成分，瞬时频率与 STFT 相邻帧相位差的关系（相位声码器的标准式）：

```
ω_inst ≈ (2π·k / N) + ( unwrap(Δφ) − 2π·k·H / N ) / H
```

⇒ **判据**：修复区与保留区的**边界**上 `ω_inst` 不应跳变 ⇒ "**修复边界的相位不连续**"
是可测的失败形态（PHAIN 正是冲这个去的）。
⚠ 经典出处本轮未核。

### 12.7 时频编辑的**效力边界**（2026-10-18，全部实测；每条都是判据）

> 这一节是 §12.1 的**工程补全**：§12.1 说了"怎么才能完美重建"，这一节说
> "**动了谱之后，改动到底落在哪些采样上、能承诺什么**"。三条都踩过、都用探针量过，
> 不是"保险起见"（`core/edit/stft.py`、`core/edit/render.py` 的注释里各挂了对应的一条）。

**① 支撑：一个谱点被改，影响会摊到整窗宽上 ⇒ 受影响采样 = 帧中心范围 ± `N/2`。**
设掩码 `M`（逐帧逐 bin 的增益），则 `x̂ = STFT⁻¹(M ⊙ STFT x)`，与源的差
`d = x̂ − x = STFT⁻¹((M−1) ⊙ STFT x)`。第 m 帧窗 `w` 的支撑是 `[mH, mH+N−1]`
⇒ `d` 的支撑 = 被掩码帧的窗**并集** = （帧中心范围）± `N/2`。
⇒ **判据**：写出的区间必须**外扩 `N`**（把整窗算进去），否则在"选区边界"上把重建硬切，
被压掉的成分会留一个**台阶**。
实测（`packaging/stft_bounds.py case_1`，素材 = 8 kHz / 0.2，掩码 −60 dB，选区 `[0.5,1.0)`）：
硬切时边界处包络 **0.1923 → 0.1167**（比值 0.61）、逐采样**最大跳变 7.56e-02**；
外扩后同一处只有 **1.44e-04**（差 **523 倍**）——1.44e-04 正是窗锥形**自然**的斜率
（0.2 摊到 `N/2` 个采样上），不是"变好了",而是**本来就该这样**。
判据落地 = `tests/test_edit_stft.py::test_band_boundary_has_no_step`（Hilbert 包络的
逐采样最大跳变 < 0.01 —— 阈值两侧分别是 1.44e-04 与 7.56e-02，落差 5×/7×，不靠手感）。

**② 覆盖：逐样本归一化的分母 `Σ_m w²[n−mH]` 一旦塌陷，浮点噪声就会被放大成波形。**
§12.1 的完美重建写成工程式就是 `x̂[n] = ola[n] / Σ_m w²[n−mH]`；分母是**结构性**的
（只由 `N/H/w` 决定，与信号无关）。帧网在某处被截断（缓冲不够、只喂整段信号）时，
分母可降到 ~1e-12，而 `ola` 的舍入误差不动 ⇒ 误差被 `1/Σw²` 放大。
⇒ **判据**：可重建区间**必须**使分母 > 阈值，否则**抛错**（不许静默置 0 或产出放大噪声）。
实测（`packaging/stft_bounds.py case_3`，白噪 0.2、1 s 整段、`pad=0`）：末一个窗宽里
出现 **6.99e-02** 的**伪波形**（同一位置源的典型幅度是 0.2 量级 ⇒ 伪影与信号**同量级**）；
覆盖守卫按预期拦下。判据落地 = `synthesize` 的覆盖守卫 + `window_sq_sum()`。

**③ 量化底**也**在**被编辑的谱里**：对 float32 素材，"没被掩码覆盖"的采样仍会动。
§12.4 说 float32/16-bit 的量化误差是**全频段**的（白噪、−145 dB 量级）；
band 掩码乘的是**整条谱**，所以连掩码带外的那些 bin（源信号的量化底）也会被一起乘下去
⇒ 波形随之变。实测：素材 3–9 kHz 的谱比谱峰低 **−145.5 dB**，band 掩码 −40 dB，
改动的绝对量 max|Δ| = 1.490e-08 = 2^-26，正好是素材峰值 0.3 的 float32 ULP (2^-25) 的一半。
（可复算：`packaging/stft_bounds.py case_2`。）
⇒ **判据**：对 float32 源只能承诺"未受影响区的改动 ≤ **1 个峰值量级的 ULP**"
（锚在**峰值**上，不是每个采样各自的量级）；"逐位不变"只能对 float64（`DOUBLE`）源承诺。
判据落地 = `test_band_span_outside_is_bit_exact`（float64）
+ `test_band_change_on_float32_source_is_at_most_one_peak_ulp`（float32）。
⚠ 这也解释了为什么"验收时先看素材的容器/位深"不是洁癖：**同一份编辑在不同位深上
给出的承诺本来就不同**。

**④ 分块不许改变结果**：块的帧网格必须落在同一条全局 hop 网格上（块长取 `hop` 的整数倍），
两侧上下文取**真实**采样（不是补零，否则窗内的谱被人工零填污染），只输出中间那段
⇒ 任意块长导出**逐位相同**。判据落地 = `test_chunk_size_does_not_change_the_result`。
（这是"性能与正确性同时要"的形态：分块是为了内存，但它**不许**动结果。）

**⑤ 掩码**形状**只谈代价，不谈"更干净"**：软掩码在**这个结构里**买不到东西。**
文献（谱减法一脉）建议"留**谱底** + 增益在**时间上平滑**"来压 musical noise，
但那套机制的**前提**是"增益由带噪估计**逐帧随机**导出"；我们的掩码是**选区内常数增益**
（确定性）⇒ 帧间增益抖动的方差为 0，**机制不存在**。实测（`packaging/mask_tradeoff.py`，
4 种掩码 × 2 种写回 × 4 列）：
* 谱底 −40 dB：核心压制度 −60 → **−40**（花 20 dB），包络跳变**一模一样**（1.4e-04）；
* 时间锥形 50 ms：核心压制度不变，但"边界 +5ms 处"从 **−42.3 dB 掉到 −3.1 dB**
  （花 50 ms 选区精度），换来的包络跳变只从 1.4e-04 到 8.7e-05（1.6 倍，本就在噪声级）；
* "不外扩跨度、靠锥形压台阶"是**假需求**：`cut/hard+taper` 的台阶 1.0e-02 仍比当前
  `wide/hard` 的 1.4e-04 **差 70 倍**；带外污染在 8 个变体上全是 **−0.00 dB**。
⇒ **判据**：任何软掩码要进内核，必须先拿出"**可测的**改善（且不是靠少压/压偏换来的）"，
否则就是凭空加机制——本仓禁止。⚠ 等编辑从"乘常数"升级到"**挖点/补点**"
（时频修音 / declip / declick）时，"挖"的机制才出现，那一项要**重开**。

### 12.8 去削波：**不等式约束 + 带限投影**——以及为什么"局部插值"是错的（2026-10-18，全实测）

> 这一节是 §12.2 的**工程落地判据**：§12.2 说"削波给的是可辨识的**约束**"，这一节说
> "**怎么用这些约束去重建，以及哪条路走不通**"。全部数字出自 `packaging/declip_probe.py`
> （同一把尺子 `metrics.sdr_db` + `metrics.energy_ratio_db`）、判据在 `tests/test_edit_declip.py`。

**① 削波是"已知位置的**不等式**约束"，不是"已知值"。** 硬削波 `y = clip(s; c)` 逐样本给：
`|s| ≥ c` 且 `sign(s) = sign(y)`（饱和样本）、`s = y`（其余）。⇒ 重建问题的两个约束集：
**带限**（`s` 的谱在内容带宽 `B` 以上为零）+ **一致**（非饱和样本逐位等于观测）；
外加**削波不等式**（饱和样本 `|x| ≥ c` 且同号）。三者都是**凸集** ⇒ 交替投影（POCS）适用。

**② 落地 = 三相交替投影**（`core/edit/declip.py`）：每轮
`rfft → 砍掉 > B 的 bin → irfft`（带限集）→ **已知样本写回原值**（一致集）→
`x = sign·max(|x|, c)`（削波集）。已知样本每轮写回 ⇒ **只改饱和样本**，
区外/区内非饱和样本**逐位不变**（判据：`test_only_saturated_samples_change`）。
⇒ 算法族锚点：**Papoulis 1975 / Gerchberg 1974「已核」**（带限外推的交替投影）；
**Rajmic, Záviška, Veselý, Mokrý, Axioms 8(3):105, 2019「已核」**（投影类算子用于去削波）。

**③ 判据：局部插值是**错的**（"更好的修复"能是负的）**。饱和样本的观测 `±c` 其误差
**被"越出 `c` 多少"限住**——轻削波的基线 SDR 本就很高（实测 43.5 dB）⇒ 任何重建必须**胜过
它**才算修好。实测四种候选（带限白噪，SDR dB）：

| 候选 | light | moderate | severe |
|---|---|---|---|
| 基线（削波信号本身） | 43.5 | 23.3 | 10.1 |
| 线性/三次多项式插值 | 21.3（**更差**） | 8.5（**更差**） | 1.6（**更差**） |
| 三次样条 | 22.6（**更差**） | 9.8（**更差**） | 1.2（**更差**） |
| 带限 + 削波不等式（落地） | **312.8** | **42.8** | **14.1** |

**机制**：插值用**不相关**的锚点去猜，估计方差远大于那点"越出量" ⇒ **越修越远**。
⇒ **判据**：修复算子必须报"修**前**"的基线 SDR（否则无从判断是否真的修好）；
**只为了"看起来做了事"而改样本，是负贡献**。工程界的 Audacity ClipFix（三次样条 + 95% 门限）
正是被否决的这一族。锚点：Záviška et al., IEEE JSTSP 15(1), 2021「已核」（逐算法评测）。

**④ 效力边界（全部实测，写进审计与 CLI）**
* **`B` 必须由调用方给**（本模块**不估**）：`B` 取窄 ⇒ 退化到"不改"（不反伤，见 §8 表）；
  `B ≥ 奈奎斯特` ⇒ 带限集是全集、没有约束可利用 ⇒ **逐位不变**（记 `noop`）。纯 P-G（无不等式）
  在 `B` 偏窄时会**反伤**（severe ×0.5 带宽 ⇒ 0.47 dB）——不等式投影把它拉回"不改"。
* **提升随饱和变密而变小**：light +269 / moderate +19.5 / **severe +4.0 dB**；与
  Záviška/Rajmic/Mokrý, Signal Processing 192 (2022)「已核」的同向结论一致
  （"提升随输入 SDR 增大而增大"）⇒ 密集削波是本方法族的**边界**，不是调参问题。
* **`c` 要取自"被编辑文件自己"的样本**：float32/整型存回后样本是**量化**的，拿写入前的
  理论电平去比会把饱和集合判空（实测：`|y| ≥ 0.5225` 在 float32 存回后**一个都匹配不到**）
  ⇒ `ceiling=None` 时取**本段观测峰值**（审计记 `ceiling_source`），永远精确命中"到达极值"的样本。
* **不是位精确**：重建改的是饱和样本（浮点运算），**非饱和样本**才逐位不变——别把两者混为一谈。
* **不能分块**：带限是**全局**约束，切块会在接缝上留台阶 ⇒ 本路径把**选区**整段载入内存
  （内存 ≈ `选区采样 × 声道 × 8 B × ~4`），这条与 §12.7 ④ 的"分块不许改结果"是**两回事**。

### 12.9 内容带宽 `B` 从哪来：**读"砖墙"，不读"能量滚降"**（2026-10-19，全实测）

> §12.8 ④ 把 `B` 定义成**调用方给的输入**，并留下"那谁来量它"这个问题。这一节把它补齐。
> 实测表与检索锚点在 `docs/editor_research.md §9`（本节只写**判据**）。

**① 谁给 `B`（不是编辑层自己估）**：编辑层**不 import 测量层**（`core/edit/__init__.py` 的模块边界）
⇒ `B` 由**测量层的单一出口**给出：`spectrum.content_bandwidth(f, db, fs, thresholds)`，
由边界层（`edit_cli`）喂进 `DeclipOp`。口径写在那个函数里，**不许在 CLI 再抄一遍**。
（对象名与文献对齐：BWE/语音超分一脉称 **effective bandwidth / `f_eff`**。）

**② 判据（口径写死，`packaging/bandwidth_probe.py` 实测）**
* **有砖墙截止** ⇒ `B = cutoff`。这是**边缘估计**，且已校准（§1.6：合成砖墙网格 ≤1.3%）；
  实测 48 kHz 下 6–21 kHz 网格最大偏差 **0.49%**，**moderate 削波后砖墙证据仍在**（+0.0%）。
* **没有砖墙** ⇒ `B = 奈奎斯特`，`source="nyquist"` = **"没有可用的带限先验"** ⇒
  去削波**逐位不变**（审计记 `noop`），**不许**假装修了。
* **不许拿能量滚降点当 `B`**：`rolloff95` 是 **spectral rolloff point** 家族
  （"总能量 95% 落在其下的那个频率"）——**能量分布的统计量，不是边缘估计**。
  实测它系统偏低（砖墙 −4.9%、谐波音 −17.5%、自然滚降素材给出 12.5 kHz 而真实内容到 ~20 kHz），
  拿它当 `B` 会把 SDR **修坏**（端到端 **−1.5 dB**；用 `cutoff` / 真值是 **+34.2 dB**）。
* 另一条被**实测否掉**的替代路："只用**没有饱和样本**的帧"量谱 ⇒ **0/10 帧可用**
  （饱和样本沿波形峰散布，任何长度的帧几乎都含至少一个）。**别再试**。

**③ 效力边界（全部实测；调用方必须看得到）**
* **severe 削波**（饱和 >20%）后砖墙证据被削波谐波**填掉** ⇒ 自动读数退回奈奎斯特
  ⇒ 去削波逐位不变（与 §12.8 ④"提升随饱和变密而变小"**同源**）。
* **素材太短**：canonical 谱走三分位取样，**长度门槛实测在 0.90–0.95 s 之间**（0.95 s 有、0.90 s 无）
  ⇒ 量不出谱时**明确拒绝**自动定带宽（不许猜一个 `B`）。
* **低截止素材**（截止点 < `cutoff_min_hz`）：`detect_cutoff` 按既有口径**拒绝给读数** ⇒
  自动 `B` 退化为奈奎斯特。**保守但不是最优**（那种素材其实真的带限）——如实挂账，见 `§9.5`。

**④ 可审计**：审计记录带 `bandwidth` 与 `bandwidth_source ∈ {given, auto_cutoff, auto_nyquist}`
——"依据哪条测量"是修复记录的一部分（`DeclipOp.bandwidth_source`，只作来源记账、**不参与算式**）。

### 12.10 去削波的**可辨识性**：解集维数与"加迭代也没用"（2026-10-20，算出来的 + 实测验证）

> §12.8 ④ 把 severe 的"提升只有 +4 dB 量级"记成**现象**。这一节给出**机制**：它不是
> "迭代不够"，而是**解集不唯一**；而且这件事**可以事先算出来**。实测与检索见
> `docs/editor_research.md §10`。

**① 解集维数（推导，非拟合）**。可行解集 `C_lin = {带限(B)} ∩ {已知样本 = y}`：
* 带限子空间的**实维数** ≈ `2·#bins(f ≤ B) ≈ (B/(fs/2))·N`
  ——依据**时间-带宽自由度**这条经典结论（带宽 `B`、时长 `T` ⇒ 约 `2BT` 个自由度；
  **Landau & Pollak 1962, BSTJ 41:1295–1336「已核」**）；
* 已知样本给 `(1−f)·N` 条（近似）独立线性约束，`f` = 饱和占比。

⇒ **解集维数 / N ≈ B/(fs/2) − (1−f)** ⇒ **欠定（解不唯一）⟺ `f > 1 − B/(fs/2)`**。
即：48 kHz、`B=18 kHz` ⇒ `f > 25%`；`B=21.6 kHz` ⇒ `f > 10%`。

**② 判据（实测验证，`packaging/sparse_declip_probe.py` 的"欠定判据验证"）**。
同一份 severe 素材（`f = 22.4%`），只改**给的 `B`**：

| 给的 `B` | 余量 `(1−f) − B/(fs/2)` | POCS 400 → 8000 次 |
|---|---|---|
| 18000（真值） | **+0.026（定解）** | 20.93 → **23.14（一直在涨）** |
| 20000 | −0.057 | 16.13 → 17.07 |
| 21600 | −0.124（欠定） | 13.58 → 13.69（**钉住**） |

⇒ **余量 > 0 ⇒ 加迭代有效；余量 ≤ 0 ⇒ 加迭代无效**（过松弛也无效：ω=1.5 只把 13.58 抬到 13.61）。
⇒ `declip.reconstruct` 把它如实记进 `stats`：`ambiguity_margin`（正 = 定解）与 `ambiguous`。
**这条告警的意义**：用户不会再"多跑几个小时等它变好"——本项目对"修不了"这件事也要**给得出依据**。

**③ 还要报"还能不能动"（两量必须一起看）**：`stats["step_rms_db"]` = 迭代**末步**相对本段的 dB；
`converged` = 末步已到**浮点精度**（`≤ 1e-12 ×` 本段 RMS，**数值判据**，不是手感门限）。
⚠ **欠定时这两个量会互相打架、必须一起读**：实测欠定侧 step 从 −75 dB 走到 −141 dB
（"还在动"），而 SDR 钉在 14 dB（"没变好"）⇒ 只报 step 会误导，故 CLI 把两者**并列打出来**。

**④ 稀疏先验不落地（判据不过就不加）**。候选：analysis-ℓ1 的 ADMM（`minimize ‖A x‖₁ s.t. x ∈ C`，
`A` = 本项目 WOLA STFT，`S A = I` 且 `A*A = diag(Σw²)` ⇒ x-update 有闭式 `P_C(S(z−u))`）。
两种素材实测（SDR）：**谐波音（稀疏）** 46.7 / 16.6 / 7.7 vs POCS 40.6 / **17.1** / 7.6；
**带限白噪（最不稀疏）** ~50 / 31.6 / 12.8 vs POCS **45.8** / **40.4** / **13.6**
⇒ 只在"稀疏素材 + 轻削波"这一角胜出（+6.1 dB），其余全面不如 POCS，且更慢更复杂
⇒ **不进内核**（ℓ1 先验的前提是素材稀疏；白噪上它**直接不成立**）。

### 12.11 去咔哒：**难在检测，不在修**（2026-10-20，全实测）

> 实测与检索见 `docs/editor_research.md §11`；判据在 `tests/test_edit_declick.py`。
> 与 §12.10 的结构一样：先把**口径与阈值**量出来，再落地。

**① 残差口径（判据：经典两点预测）**：`r[n] = y[n] − (y[n−1] + y[n+1])/2`。
对 `f ≪ fs` 的平滑内容 `r ≈ (2πf/fs)²·|y|`（实测滑音 `f=750 Hz` ⇒ 量级 **0.007**），
咔哒样本上 `r ≈ 幅度`（0.9）⇒ **信噪比由口径给出**。
⚠ "邻域中值残差"**实测否决**（正弦的局部中值本身偏离样本值 ⇒ 残差被波形主导，15% 假阳性）。

**② 尺子（判据：全段 MAD）**：`s = median(|r|)/0.6745`。**实测比过局部滑动尺子**：
同一误报率下全局更优（合法瞬态 α=5：全局 **+6.53** vs 局部 **−3.71** dB）。
⇒ **全段**统计量 ⇒ 与 §12.7 ④ 的分块口径**不同**：本算子**不分块**（分块会让每块各有一套尺子）。

**③ 阈值（判据：代价不对称 ⇒ 先压误报）**：默认 **`α = 5.0`**。实测代价表（ΔSDR dB）：

| α | 谐波音 | 带限白噪 | 合法瞬态 | 平滑滑音 |
|---|---|---|---|---|
| 3 | +13.75（FPR 9.4e-5） | **−9.96**（FPR 3.0e-3） | **−7.36**（FPR 3.1e-3） | +11.51 |
| 4 | +14.24 | +1.02 | +5.04（FPR 1.3e-4） | +40.60 |
| **5** | +3.63（FPR **0**） | +1.99（FPR **0**） | +6.53（FPR **0**） | **+40.60** |

⇒ **误报的代价不对称**：FPR 到 ~1e-3 就把信号**修坏**，而 TPR 掉一点只让收益从 +14.2 变 +3.6
⇒ 规则 = "**先压误报、再看收益**"。工程界的默认（`4σ`、`10×局部 RMS`）**同量级**，
我们取 5σ 的**理由有数据**（不是手感）。

**④ 效力边界（写进算子 docstring 与审计）**
* **收益由素材的可预测性决定**：平滑 **+40.6 dB**、合法瞬态 +6.5、谐波音 +3.6、
  **带限白噪只 +2.0**（噪声本身不可预测 ⇒ 预测残差里没有可分离的咔哒成分）；
* **合法瞬态会被误伤**（闭源标杆专门用"第二级复核"处理这一类，见 §11.3）⇒ 我们把阈值取在
  保守侧，且**改动面 > 0.5% 时主动警告**；本轮素材上**实测 0 误报**（判据钉住），
  但**不代表所有素材**；
* **承诺**（可逐位验证）：**只改检出样本** —— 选区外**逐位不变**、选区内**未检出样本逐位不变**。

### 12.12 去咔哒的**第二级复核**（宽度守卫）与两类缺口（2026-10-21，全实测）

> 实测表见 `docs/editor_research.md §12`；判据在 `tests/test_edit_declick.py` 的"5. 宽度守卫"一节。

**① 宽度守卫的口径**：只接受**检出段宽度 ≤ `max_run`** 的段（默认 **4** 采样）。
依据是**代价表**（平滑音 + 5 ms 起音，α=5）：

| `L` | 1 采样咔哒 | 2 采样咔哒 | 合法起音"离原素材" | 被改采样 |
|---|---|---|---|---|
| 无守卫 | +39.14 | +37.37 | **30.55 dB** | 300 |
| 3 | +39.14 | **丢** | 65.29 dB | 16 |
| **4** | **+39.14** | **+37.37** | **56.51 dB** | 40 |

⇒ **4 = 不丢掉任何能修的咔哒的最小值**（1/2 采样咔哒的检出段宽度分别是 3/4），
且把合法起音的破坏降了 **26 dB**。**不是凭空的门限**：它由"丢不丢咔哒"这条**离散事实**定出来。

**② 挡不住的**：亚毫秒起音（0.2 ms 的检出段宽度也是 2，与咔哒重叠）⇒ 守卫无效；
噪声素材上的起音本来就检出 0（残差尺度被噪声抬高）。

**③ 一个没说透的缺口（本轮量出）**：`r[n]` 在**平台内部** ≈ 0 ⇒ **宽度 ≥3 的矩形咔哒只修两个边**
（ΔSDR：1→**+39**、2→**+37**、3→**+1.5**、8→**+0.5** dB）。候选修法"按幅度沿两端扩展"
**实测否决**（残差尺度不是幅度尺度，扩展会一路吃穿信号）⇒ 需**台阶检测器**，本轮挂账。

**④ 可审计**：审计带 `max_run`、`rejected_runs`（被守卫挡下的段数）——"复核挡掉了多少"必须可见；
`--max-run 0` 显式关闭守卫（此时警告面更大：实测改动面 300 vs 40 采样）。
