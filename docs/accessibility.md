# 无障碍自查（E3）：按 Qt 五方面的三态表

> **本文件不宣称"符合 WCAG / 无障碍标准"**——它只是"按 Qt 官方无障碍五方面
> 自查"的结果记录。措辞纪律与 clreq 那条同源：没有做过符合性测试，
> 就不许说"符合"。
>
> 复算：`python packaging/a11y_report.py`（离屏，约 20 秒）；
> `--strict` 在有**未登记**的"不支持/部分支持"项时返回 1。

依据：Qt 官方 `doc.qt.io/qt-6/accessible.html` 的五个方面——
**Scalable UI / Keyboard Navigation / Colors & Color Contrast /
Sound & Speech / Assistive Tools**。

## 三态表

| 方面 | 状态 | 实测与理由 |
|---|---|---|
| **可缩放 UI** | 支持 | 字号 8 级令牌（B1 交付）+ 高 DPI 属性已开（`AA_EnableHighDpiScaling` / `AA_UseHighDpiPixmaps`，`MainWindow.__init__`）。按屏宽缩字阶（B14 `theme_for_width`）。 |
| **键盘导航** | 支持 | 离屏 Tab 链实测覆盖：工具栏 6 按钮、搜索框、筛选框、文件表、**全部 8 张画布**、侧边栏全部导航项。全局快捷键：`Ctrl+O`/`Ctrl+Shift+O`（加文件）、`F5`/`Ctrl+R`（分析）、`Esc`（停止）、`Ctrl+E`（导出）、`Ctrl+L`（清空）、`Ctrl+D`（主题）、`Ctrl+M`（风格）、`Ctrl+G`（种子色）、`Ctrl+T`（设置）、`Ctrl+K`（命令面板，可到任意视图）、`Delete`（移除）、`Ctrl+F`（搜索）。画布收 `F` 键（全屏无损放大）。 |
| **颜色与对比度** | **部分支持** | 文字对比度 15 条判据全达标（`palette_report.py`）；**焦点环** `border_focus` 对 surface/bg 实测 4.62–5.97:1 ≥ 3:1（新增判据已进 `palette.CHECKS`）。**缺口：输入描边 `border` 实测 1.18–1.33:1 < 3:1**——见下。 |
| **声音与语音** | **不适用** | 本工具是**音频分析工具**：用声音播报结果会污染用户正在聆听/分析的听音环境，且播报声与被测音频同信道。明确不适用，给理由（不许为了"补齐五方面"硬做一个语音功能）。 |
| **辅助工具（屏幕阅读器）** | **部分支持** | 主控件全部有可访问名（8 张画布逐个设置，含文字替代描述指向元数据页 KV 表；搜索框/筛选框/文件表/工具栏按钮同）。**缺口：图表内部数据点（逐段 LUFS 序列等）没有逐点朗读替代**——Qt 无原生图表无障碍 API，逐点暴露属后续批次。 |

## 诚实登记的缺口（KNOWN_GAPS）

登记不是免责——是"我们知道、且现在不改，理由写在这里"。

1. **输入描边 ≈1.2:1（颜色与对比度，部分支持）**
   WCAG 1.4.11 对控件边界要求 3:1，本项目实测不达标。
   **为什么不修**：抬高全边框对比度 = 改 B 块七轮定下的视觉语言
   （弱边框是那套美学的一部分），属 B 块的决定，不是 E3 顺手能改的。
   **已做**：`palette.CHECKS` 按 1.0 登记该条目（与"卡片描边"同处理），
   报告里**显示实测值**（1.18–1.33:1），`tests/test_ui_a11y.py` 钉住
   "登记条目不静默变绿"。
2. **图表逐点朗读（辅助工具，部分支持）**
   画布有可访问名与文字替代**指向**（数值权威出口在元数据页
   「全部测量指标」KV 表），但图表内部数据点没有逐点朗读。
   **后续**：需要逐序列暴露（如逐段 LUFS 的可访问接口），属下一批次。

## 本批次做的（E3 第一轮）

- `packaging/a11y_report.py`：五方面三态表审计（离屏，`--strict` 守未登记缺口）。
- `src/audiocheck/ui/charts.py`：`BaseCanvas.paintEvent` 补**焦点环**
  （自绘控件 QSS 管不到；用与 QSS 焦点环同一令牌 `border_focus`）。
- `src/audiocheck/ui/window.py`：8 张画布逐个 `setAccessibleName` +
  `setAccessibleDescription`（文字替代指向）；搜索框 / 筛选框 / 文件表
  补可访问名。
- `src/audiocheck/ui/palette.py`：`CHECKS` 新增 4 条非文字对比度判据
  （焦点环 ×2 按 3:1；输入描边 ×2 按 1.0 登记）。
- `tests/test_ui_a11y.py`：7 条机器判据（可访问名 / 键盘 Tab 链 /
  焦点环对比度 / 焦点环**像素**判据——聚焦前后 render 基线噪声为 0、
  聚焦后边框带出现差异）。

## 已知未做（诚实记账）
