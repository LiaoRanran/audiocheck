```
审计摘要一致（不随路径/时刻漂移）：是
```

## 这一版做了什么

**从"音频体检"扩成"体检 + 修复"。**

### 五修复算子（每个都有合成语料判据 + 实测效力边界）

| 算子 | 方法 | 实测 |
|---|---|---|
| **去削波** | POCS（带限投影 + 削波不等式交替，128 次） | 中度削波 +41 dB；**欠定时如实报 `ambiguous`**（多个合法解，不假装唯一） |
| **去咔哒** | 两点残差 + 双尺度 MAD + **长窗中值台阶臂**（级联） | 单样本 +23 dB；**多平台 w=3 +24 dB** |
| **去嗡** | 零相位陷波级联 Q=10 | 21 格频率抖动实测：Q=10 全胜或打平 |
| **去噪** | Wiener-DD + **逐帧噪声底跟踪**（bin 中位数比值） | 稳态 +12 dB；**台阶噪声床 +2.74 → +9.40 dB** |
| **decrackle** | — | **实测判"不落地"**：它就是更松的 DeclickOp，误伤真实信号 |

### 可审计（差异化核心）

- **机器审计**：每操作「改了什么 / 依据什么 / 实测多少」
- **`audit_digest`**：跨机、跨时刻可核对的记录摘要
- **`kernel_digest`**：渲染实现自证（实现没被改过）
- **`evidence_levels`**：每个数字标〔实测〕〔推导〕〔设定〕——量具可靠性一眼可见
- **SHA256 证据链**：源/产物内容哈希（法证口径）
- **人读报告**：Markdown，机械排版，`None` 一律写"未测"而非 0

### 编辑语义（v1.1.2 更新）

- **同域多算子选区重叠不再拒绝**：改为**顺序串联**（后一个作用在前一个的结果上）
  ——操作栈的顺序就是语义，与混域链式同一条原则（不重叠仍走单趟，性能不变）
- **套索键盘微调**：方向键平移、Shift+方向键缩放、Alt+↑/↓ 频率平移，并夹紧到文件范围（画完不必重画）
- **Inspector 顶点级编辑**：顶点表加选中标记，↑/↓ 选顶点后即可逐点微调（套索能力的上限形态：
  画完不仅能整体挪，还能逐点修）；经 `replace_at` 落回栈（构造新 op ⇒ 非破坏语义不变）

### 工作站与工作流

- REAPER 式三栏工作站（频谱/波形/播放头/选区/操作栈）
- **矩形 + 多边形（套索）选区增益**，ROI 快速重绘 **27.9×**
- 批处理（逐项隔离 + per-job 审计/报告）、A/B 对比、修复链预设、项目记录
- CLI：`--declick/--declip/--dehum/--denoise/--gain --poly/--chain/--report/--batch`

## 已知边界（诚实清单）

- **单平台**（Windows 优先），无 VST3/CLAP 插件形态
- 修复算法是**经典方法**（POCS/AR/Wiener），未用神经网络——刻意选择
  （确定性 + 可审计，同文件两次修复必须同结果）
- 真实曲库验证为**单用户语料**（n=448），外部有效性有限
- 去噪**不保护瞬态**（实测 −13.6 dB 峰值），如实记账不隐藏
- 台阶型咔哒的**孤立单平台**检不出（机制已探明：中值残差 run 只有尾缘 1–2 宽）
