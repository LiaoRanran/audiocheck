## 3. 冲突提案（CS，改口径要报数，本轮只提案不动判据）

- **CS1｜氛围彩度 vs「高彩 ≤1%」结构判据**：整图 C>0.10 — **G2 暮光纸 0.01%（过线内）**，**G1 极光 66–79%（远超）**。
  G1 是 GR 忠实氛围场（GR bg.jpg 97.2% 彩色，用户日常校准）；我们的「≤1% 高彩」写的是 **chrome 中性底**时代的口径。
  **提案**：把高彩预算重新定义为「**UI chrome + 数据墨 ≤1%，氛围层单列、有自己的振幅上限**」；两档氛围给一条振幅带（G2=安静 / G1=极光），由用户定默认档与阈值曲线。**这不是退步，是口径从「底中性」迁到「底氛围」。**
  - **✅ 已判（2026-10-14 用户）**：`b12s1_bad.png`（**G1 极光**态）被用户点为「最好看」⇒ **氛围默认 = G1 极光；CS1 结案，口径按上述两层拆**（氛围层单列振幅带，chrome/数据维持 ≤1%）。
- **CS2｜圆角纪律缺仪器档**：现有 `radius` 只 lg/xl=12/16px。**提案**增 5px 仪器档（D1），登记值对齐 GR arc1=5（不取整数巧合，取实测）。
- **CS3｜字号层级 ≤5 种 ⇄ 同屏比例成组**：样板屏 default 集 = 40/22/16/14/12/10（6 种）。**提案**改判「同屏字号比例必须成组（hero:body ≈ 3.3:1 …）」，附实测比例集合由你核。
- **CS4｜D2 间距刻度 / D3 阴影色**：本轮未出两版实测（`fs/spacing` 用 4-倍数占位、阴影用 GR 纯黑）。**待**：出 GR 刻度 vs 4-倍数两版、纯黑 vs 偏冷两版，实测密度差/脏感，PM 定。
- **CS5｜光随底色已实现**（`veil_alpha`），撤销「常数 alpha」旧口径的提案已附数据（面板 L 0.907–0.915 稳定偏亮、氛围残留随底）。

## 4. 诚实边界

- 这是 prototypes 完成品，非 `src/` 落地；**只渲了 `default` 字号集**（artwork/S2 为同语法变体，未再出图）。
- Roon §2 缺真 UI 材料（合并账三家：GR+RX+Ableton）；Ableton 标「社区重建·中置信」；RX 数仅「对外视觉语言」。
- 镜面闪点不能造假（每像素真实测量值）——样板屏给的是「材质与色 + 层次语法」，不伪造 specular。
- **用户判决（2026-10-14）**：`b12s1_bad.png`（G1 极光 · 不达标态）「最好看」⇒ 氛围默认 = G1 极光，CS1 结案。
  **观察（推断）**：不达标态的**玫瑰判定带与 G1 玫瑰/紫调氛围同族**，和谐感可能贡献了「最好看」。
  ⚠ **判定语义色不变**（达标=绿 / 不达标=玫瑰 / accent，功能色，红线④）——观感不能改语义；若用户指的就是「状态」而非仅氛围，则「玫瑰 accent + 极光氛围」是要固化的搭配，另议。
