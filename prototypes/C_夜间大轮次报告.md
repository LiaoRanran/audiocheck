## C1 区分力检验（P0-1，`04954f0`）

### 为什么必须做

`AGENTS.md` §3.4：

> 一个阈值如果把人全判到同一侧，它就是没用的。**新加任何阈值都要跑一次这个检验。**

而本项目**此前一次都没跑过**（内核审查报告 P0-1）。

### 交付物

* `packaging/threshold_survey.py` —— 对标 `headphone-lab/src/audibility_survey.py` 的口径。
  **44 个合成语料**（临时目录，不入库），按每个阈值的两侧**定向造样**；
  逐字段报 **越阈比例 / 双向分布 / 是否只判到同一侧**；全落一侧 ⇒ 打印"**无区分力**"。
  `--strict` 有盲区则返回非 0；`--json` 落盘。
* `tests/test_c1_threshold_survey.py` —— 把普查**挂进测试**（19 秒，可接受）。
  三条判据：① 无字段失区分力 ② 截止点检出率 100%
  ③ **`Thresholds` 每个字段都在普查映射里**（防"加了阈值但普查没跟上"）。
* `docs/thresholds.md` —— 总账（区分力实测表 + C2 出处占位）。

### ★ 关键发现：第一轮报的 5 个"无区分力"**全部是语料造错**

| 字段 | 第一轮 | 真因 |
|---|---|---|
| `bit_gap_warn` | 全落一侧 | **量化在电平归一化之前** ⇒ 归一化乘非 2 的幂的因子，**把低位重新填满**。分析器把"24bit 装 16bit"**正确**读成了"真 24bit"。 |
| `width_narrow_db` | 全落一侧 | **反直觉**：`width_db = 10·log10(side/mid)`，`side=(L−R)/2` ⇒ **让 R 变小并不缩小 side**。`R=0.01L` 时 width ≈ 0 dB，**根本不是单声道**。近单声道必须 `R = L(1−ε)`（ε=0.032 → −35.8 dB）。 |
| `lra_flat` | 只有 1 个样本有定义 | **恒定电平的正弦算不出 LRA**（`lra=None`），必须给起伏（±0.4 dB 慢速调幅 → lra=0.2）。 |
| `advice_low_pct` | 全落一侧 | 白噪的频段占比是平的，`sub+bass` 到不了 60%。补 150 Hz 低通样本。 |
| `advice_upper_mid_pct` | 全落一侧 | 同上，白噪的 `upper_mid` 恒 > 15%。 |

**修完语料后：全部字段两侧都有样本**（`--strict` 返回 0）。
⇒ **立一条操作纪律**：这条判据失败时**先查语料、再查阈值**。
反过来做就是**调阈值去迎合一个造错的语料** —— 那是把测量工具往错的方向校准。

### 一个必须写清的边界

`min_drop_db` / `min_stop_db` / `cutoff_min_hz` / `cutoff_need` / `conf_slope_span`
是**算法参数**，不定义判定 —— 它们决定的是"**能不能检出截止点**"。
所以它们**不做两侧分布检验**（算法参数"全落一侧"是正常现象），只报**检出率**：
合成语料 44/44 = **100%**。
